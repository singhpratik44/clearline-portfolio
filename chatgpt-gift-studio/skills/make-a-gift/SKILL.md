# Make a gift

Start with what the user already told you about the recipient, occasion, budget and one interest or shared memory. When that is enough, make something in the first response. A relationship or nickname is sufficient. If the request is for a surprise, avoid asking for the recipient's contact details.

## Choose the form

For physical gift ideas, call `make_gift_plan` with the user's actual preferences. Give the most promising idea first, explain what detail about the recipient it fits, and include a practical personal touch. Use the tool's approximate price ranges. If none fit the budget, suggest a free activity or a handwritten message.

For a greeting the user can share, call `create_shareable_gift`. Preserve any wording the sender supplied and show the resulting link. Anyone holding the full link can read the greeting. Describe sharing as the sender's next action. If the person wants a printable thank-you, offer a short note they can paste into the [printable postcard maker](https://singhpratik44.github.io/clearline-portfolio/gifts/holiday-thank-you/).

For a card signed by several people, offer the [group card maker](https://singhpratik44.github.io/clearline-portfolio/gifts/team-card/) and one specific note to start the card. Let the organizer choose how to collect contributions.

For a gift exchange, use the [Secret Santa draw](https://singhpratik44.github.io/clearline-portfolio/gifts/secret-santa/). Have the organizer enter the roster in the browser and share each person's individual reveal privately. Keep the roster, assignments, planning notes and purchases out of group messages.

For a gift someone can make or play, select one relevant free activity from the table. Give the recipient a one-sentence challenge or dedication. Use the [web Gift Finder](https://singhpratik44.github.io/clearline-portfolio/gifts/finder/) when a person wants to compare more APERTURE items. For free-only requests, explain that entering 0 as the dollar cap filters for free items.

| Recipient's interest | Free gift | Something personal to try |
|---|---|---|
| Football, makeup or team colors | [Game Day Color Lab](https://singhpratik44.github.io/clearline-portfolio/shop/seasonal/#game-day) | Choose three colors from a shared game-day memory and assign one to each receiver route. |
| Maps, games or city planning | [Side Street](https://singhpratik44.github.io/clearline-portfolio/shop/city-challenge/) | Ask which two streets they would add. Let them try their answer before giving a hint. |
| Thanksgiving or family traditions | [Thanksgiving Table Draft](https://singhpratik44.github.io/clearline-portfolio/shop/seasonal/#table-draft) | Write one guest's name on the front and a question about a favorite family tradition on the back. |
| Coding, storytelling or making games | [APERTURE Academy pathways](https://singhpratik44.github.io/clearline-portfolio/coding-lab/academy/pathways/) | For a Scratch fan, suggest the playable postcard with two endings. For a Python learner, offer a tiny branching story using their recipient's favorite place. |

Give the result first. Include a link only when it helps the user make, open, print or share the gift they requested. Avoid unrelated promotions, paid checkout instructions and assertions that a recipient has received anything.
