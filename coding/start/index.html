Step 2 · First tiny project

Make a Python guessing game

Try this in a Python 3 environment. Read each line, run it, and change the secret number.

secret = 7
guess = int(input("Guess a number from 1 to 10: "))
if guess == secret:
    print("You got it!")
else:
    print("Try again! The number was", secret)

Three experiments: Change the secret number; add a hint for guesses that are too high; then add a loop to allow three attempts. If the program crashes, read the error and check whether the input is a number.
