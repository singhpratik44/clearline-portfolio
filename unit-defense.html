Agent communication graph — fault-tolerant by construction

Growth, ops, and compliance agents coordinate over an r-robust graph: every agent is reachable through enough independent paths that up to faulty agent(s) cannot capture a network decision. Edges carry information budgets — centers report what they must, not everything they can — so the graph stays functional under under-reporting.

Deliberation order is fixed: compliance speaks first, then ops, then growth. The first voice dominates outcomes in multi-agent panels, so the safety agent always frames the decision.

Quantum view — the network as a syndrome graph

Treat peer centers as qubits in a surface code: adjacent centers run correlated playbooks, so a parity check between neighbors should agree. An error chain flips parity only at its endpoints — exactly like a physical error chain in QEC. The decoder then solves a minimum-weight perfect matching on the fired detectors: pair them along the shortest total path, and the matched edges are the most likely error locations.

This is the Sparse Blossom / PyMatching architecture (decodes a distance-17 surface code in <1µs/round) applied to network operations — and the 2026 neural-decoder line (NMWPM: a GNN+Transformer learns the edge weights, reaching 17.9%/10.95% thresholds near maximum-likelihood bounds) is the upgrade path: learn which peer-links are noisy instead of treating all parity checks equally.

Below-threshold behavior. Governance is "below threshold" when layered gates suppress errors faster than they enter. Curves: escape probability ∏(1−q)k-style scaling for k verification layers vs. the diagonal (incoming error rate). More layers → deeper suppression.
