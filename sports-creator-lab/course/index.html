Sports Creator Academy

Learn to code by designing real playable sports games, analyzing fictional sports data, and programming virtual robots. Every week ends with a working artifact, not a worksheet alone.

Course roadmap

Weeks 1–3 Scratch → 4–6 MakeCode Arcade → 7–9 Python → 10–11 VEXcode VR → 12 Showcase. Instructors can substitute platforms where access is restricted.

0 of 12 weeks marked complete on this device.

Instructor delivery method

  1. 0–10 min: Demo the target project and invite predictions.
  2. 10–25 min: Guided build; students narrate the key concept.
  3. 25–45 min: Independent feature development with two levels of challenge.
  4. 45–55 min: Test three cases, debug one failure, collect observable evidence.
  5. 55–60 min: Student explains what changed and selects next step.

Evidence-based 10-point rubric

Functionality 0–3 · Concepts 0–3 · Testing/debugging 0–2 · Explanation/creativity 0–2. An instructor—not software—decides scores using observed work.

Teaching adaptations

Beginners: use starter blocks and pair programming. Intermediate: add variables, conditions, or functions independently. Advanced: add measurable tests, modular architecture, and explain trade-offs. Allow keyboard-free alternatives where necessary.

Privacy: use invented teams and aliases only. Completion checkboxes and notes stay in this browser, are not verified grades, and are not uploaded to Supabase. Verify third-party age and account policies before classroom use.
