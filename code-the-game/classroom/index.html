Common Core connections

Each challenge includes an observable student task and a proposed grade 6 standards connection. Alignment is instructional mapping, not certification or a claim that coding alone satisfies a standard.

6.NS.C.6 / 6.NS.C.8

Students describe positions and distances using coordinate reasoning; extend the movement lab to a four-quadrant grid on paper.

Evidence: coordinate table and distance explanation.

6.EE.B.6

Students define a movement variable and compare the outcome of different values.

Evidence: variable definition, two test runs, and a written conclusion.

W.6.2 / SL.6.1

Students write an explanatory design reflection and discuss trade-offs with peers.

Evidence: written reflection and structured group discussion.

Reference: Common Core mathematics · Grade 6 explanatory writing. Verify grade, state, and district expectations before adoption.
