# CODE THE GAME — Standalone Teacher Guide
**Version 1 · Educator-review draft · Grades 6–8 suggested · No student login required**

These three labs run independently in a web browser. Teachers can teach them separately or as a three-session sequence. No LEGO kit, AI API, competition registration, payment, or student account is required. LEGO is a trademark of its owner; this is not an affiliated LEGO Education product.

## Lab 1: LEGO-style Robotics Mission (45–60 minutes)
**Objective:** Compose a sequence of commands to navigate a grid, debug collisions and explain a route.
- **Launch (10 min):** Discuss robot orientation and turning versus movement. Predict a safe route on paper.
- **Explore (20 min):** Build and run a sequence. Record where a collision occurs. Revise.
- **Explain (10 min):** Draw the route and annotate at least one failed attempt.
- **Extension (10 min):** On a signed-coordinate paper grid, represent positions and compare horizontal/vertical displacement.
- **Equipment:** browser only. Optional school-owned LEGO Education hardware requires separate approved software, purchasing and setup.
- **Evidence:** original prediction, command sequence, observed result, revision and reflection.

## Lab 2: Explainable AI & Data (45–60 minutes)
**Objective:** Explain a deterministic classification rule and identify errors.
- **Launch (10 min):** Explain the difference between rule-based automation and trained AI.
- **Explore (20 min):** Test thresholds 40, 50 and 70. Record number of correct predictions and at least two mismatches.
- **Explain (10 min):** Why can no single threshold correctly classify every sample? Identify missing information.
- **Extension (10 min):** Discuss sensor quality, fairness and human oversight.
- **Evidence:** comparison table, claim, supporting numbers, limitation.
- **Privacy:** use only fictional data included in the activity.

## Lab 3: Hackathon & Innovation (45–60 minutes)
**Objective:** Define a user need, choose measurable success, plan a prototype and communicate a test.
- **Launch (10 min):** Choose a community problem and ask who benefits.
- **Build (20 min):** Complete the project brief and time allocation.
- **Test (15 min):** Present a low-fidelity prototype or storyboard and gather non-sensitive feedback.
- **Exit (5 min):** Export the brief; state one design risk and one reversible improvement.
- **Evidence:** problem statement, beneficiary, success metric, test plan, 2-minute pitch.
- **Important:** The lab does not register or submit a project to any hackathon.

## Assessment rubric (0–3 each, maximum 12)
| Dimension | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Computational reasoning | None | Vague | Mostly correct | Clear, reproducible algorithm or rule |
| Testing & evidence | None | Anecdote | Two documented tests | Controlled comparisons and revision |
| Communication | None | Limited | Clear claim | Claim with evidence and limitation |
| Human-centered design | None | Mentions user | Addresses need | Tests accessibility/privacy implications |

## Proposed Common Core connections (not certification)
- **6.NS.C.6 and 6.NS.C.8:** robotics coordinate and distance *paper extensions*, including signed-coordinate work; the browser grid alone does not teach all standard requirements.
- **6.EE.B.6:** variables as quantities, especially AI threshold and robotics step or turn count.
- **W.6.2:** write an informative explanation of design and testing.
- **SL.6.1:** structured peer critique and discussion.
- These are instructional opportunities, not verified standards alignment or district approval. Local teachers must review adopted grade-level standards.

## Accessibility and technology review
- Test keyboard access, focus indication, screen reader announcements, contrast and mobile behavior with actual learners before classroom adoption.
- Do not enter real student names, private records or identifiable data into the Hackathon brief.
- For LEGO robotics hardware extensions, check current LEGO Education kits, approved software, school purchasing policies, and competition-specific equipment rules.
- All three browser labs are free and independent of external competition organizers.
