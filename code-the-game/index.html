Free sample: Your first Roblox script

Goal: make a platform respond when a player touches it. In Roblox Studio, create a Part, insert a Script inside it, and try:

View sample code
local platform = script.Parent
local debounce = false

platform.Touched:Connect(function(hit)
  local character = hit.Parent
  local humanoid = character and character:FindFirstChildOfClass("Humanoid")
  if humanoid and not debounce then
    debounce = true
    platform.BrickColor = BrickColor.Random()
    task.wait(1)
    debounce = false
  end
end)

Challenge: Change the wait time. What happens if you remove the debounce variable? Explain why the platform may change color repeatedly.
