Frequently asked questions

What happens after payment?

Stripe redirects to a private access link for the purchased lesson pack. Bookmark the entire URL including its # fragment. There are no customer accounts or automatic lost-link recovery. Contact support if delivery fails.

Is this a live course or a video course?

No. These are self-paced written coding lessons, practice labs and project guidance. No live instruction, video sessions, personalized grading or certifications are included.

Do I need extra software?

Yes. Roblox requires Roblox Studio on Windows/macOS. Minecraft requires Minecraft Education with Code Builder/MakeCode, which may require a separate license. Godot requires Godot 4 desktop. Software is not included.

What is the refund policy?

Email purchase support with order details. Requests are reviewed individually under applicable law; no unconditional refund guarantee is offered.

Are the courses officially affiliated with Roblox, Minecraft or Godot?

No. These are independent educational resources, not endorsed by Roblox, Mojang, Microsoft or Godot. Independent engine-version testing is still ongoing.
