-- Roblox Studio / Luau
local platform = script.Parent
local debounce = false

platform.Touched:Connect(function(hit)
  local character = hit.Parent
  local humanoid = character and
    character:FindFirstChildOfClass("Humanoid")
  if humanoid and not debounce then
    debounce = true
    platform.BrickColor = BrickColor.Random()
    task.wait(1)
    debounce = false
  end
end)

Questions answered

Before you buy.

Are these live classes or video courses?

No. These are self-paced written lessons with code samples, challenges, practice labs and project guidance. No tutors, live sessions, videos, personal grading or certifications are included.

What software do I need?

Roblox Creator requires Roblox Studio on Windows/macOS. Minecraft Coding requires Minecraft Education with Code Builder/MakeCode, which may need a separate license; regular Java/Bedrock is not sufficient. Indie Game Developer requires the Godot 4 desktop editor. Software is not included.

How do I receive my lessons?

After a successful Stripe checkout, the payment page redirects to a private course-access URL. Save the entire URL, including everything after the # symbol. There are no customer accounts or automatic lost-link recovery. Contact support if the redirect fails.

Can I request a refund?

Contact purchase support with your order details. Requests are reviewed individually under applicable law. No unconditional refund guarantee is offered.

Is this an official Roblox, Minecraft or Godot course?

No. These are independently created educational materials, not affiliated with or endorsed by Roblox, Mojang, Microsoft or Godot. Engine-specific exercises are still undergoing independent version testing.
