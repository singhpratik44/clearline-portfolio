APERTURE / The invisible architecture

Every decision has a lineage.

The world reacts because the dependency engine is explicit. No unobserved data are manufactured. No automation substitutes for the coach's final judgment.

TRUTH

Practice and game simulations are always labeled illustrative. Real video analysis requires the coach's own observation.

DEPENDENCIES

Shot quality depends on personnel, spacing, coverage and pressure. Development depends on training focus and recovery.

CONTRADICTION

A tactic can create a shot and still be a poor fit for a specific defense. The counter suggests a test, not a mandate.

CORRECTION

When possessions or training don't go as hoped, the model exposes its assumptions so the next decision can change.

EVIDENCE

Every committed action is recorded with its inputs, rationale, limitations and time. Export and inspect the complete state.

HUMAN AUTHORITY

Scouting input, play selection, training, film notes and simulations all require an explicit human action.

Deterministic simulation / Honest limitations

APERTURE Arena is a static GitHub Pages demonstration. It uses a seeded pseudo-random sequence and hand-authored basketball rules rather than a predictive ML model. The scouting choices, player ratings, shots and opponents are fictitious. The practice and game model does not forecast real athletic performance.

Data persists only in local browser storage when enabled. Video files remain in memory on your device; none are uploaded. Your exported JSON can be reviewed independently.
