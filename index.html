Article IV — Governing principles, common to all systems

Canonical stateOne shared structure feeds every view. No cached copies, no version drift.
Fail-safe by defaultMissing, stale, or unverified data does not pass. The proposal holds; the system never approximates.
Named ownershipEvery decision and support path has a named owner. Closed on the record, not in someone's head.
Symmetric transparencyFranchisor and franchisee see the same numbers, computed from the same state.
Safety precedes growthThe first gate is always safety/integrity. Revenue optimization is structurally subordinate.
Causal lineageEvery decision records the inputs it consumed, so corrupted data can be traced to everything it touched.
Domain-agnostic by constructionThe schema governs nodes, gates, clocks, and ledgers — not "centers." Domain packs swap lexicon and seeds; the machinery never changes.
