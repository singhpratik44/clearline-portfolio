The signal tiles

A lighthouse sends a message with four tiles. Each appears once. Read the clues to rebuild the signal from left to right.

The clues

  1. The Wave is immediately to the left of the Arch.
  2. The Star is at one end.
  3. The Dot is somewhere to the left of the Wave.
  4. The Star and the Arch do not touch.
Get a hint

Write Wave and Arch on the same slip of paper. They move as a pair. What would happen if Star occupied the far right?

Reveal the answer

Star · Dot · Wave · Arch. Dot must come before the Wave–Arch pair. If Star were last, the first three tiles would have to be Dot, Wave, Arch, putting Arch next to Star. That leaves Star at the far left and exactly one order for the other three.

Facilitator notes

Write each tile name on a scrap of paper. Have one player move tiles and the other read a clue aloud, then swap roles. Ask which clue eliminates the last alternative. For a replay, let players invent a different order and write clues for a teammate.
