Privacy first

Your records stay yours.

No public student profiles, birthdays, attendance tracking, advertising trackers or public gallery uploads. Signed-in adults only. Actual files belong in a private storage bucket.

Student data is never stored in the GitHub repository. The public 4D Universe receives only the track identifier—not the student’s name or progress.
