# Applied storefront design plugins

| Plugin | Applied output | Added cost |
| --- | --- | --- |
| DesignSystem | Reusable storefront palette, typography, focus and interaction tokens in `theme.css`, with semantic color roles and component guidance in `DESIGN.md`. | $0 |
| MotionDesign | Applied the card-stacking and press-response direction to the deck and controls. CSS timing and easing in `theme.css` provide coordinated sheet, color and press motion and a reduced-motion state. | $0 |
| Designly | Applied Typography Director's hierarchy and measure to the editorial display face, 1.07 display leading, balanced headings, 1.55 body leading and 62-character lead measure. | $0 |
| Awesome DESIGN.md | Read the index and Shopify reference. Adapted its two-polarity commerce treatment and consistent rounded primary action to the storefront's dark sample area, light catalog and pill actions. | $0 |
| BrandKit | Applied brand-identity direction to the original concentric mark, prescribing its clear space and repeating its circular geometry in the learning materials. Restored the mark as a local storefront asset and connected it to the header and footer lockups through `theme.css`. | $0 |

MotionDesign's stacking and response direction is implemented with local CSS transitions. BrandKit contributed identity application using the existing artwork. The storefront uses system fonts.
