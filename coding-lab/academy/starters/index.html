Lantern Routes

One train, one lantern, and two paths through the dark. Choose a route and a signal. Then change the story, the cost of a route, or the rule for waking the beacon.

Make it in Scratch

The starter includes the lantern sprite, both routes, a light counter, and three endings. Open the Scratch editor and choose File → Load from your computer.

Click the green flag. Hold the left or right arrow to choose a route, then hold up for the beacon or down for the bell. Click the flag to replay.

Download Scratch projectOpen Scratch editor

If Scratch is already installed on your computer, open the downloaded file there to work offline.

Make it in Python

Run the file in Python 3 using IDLE’s Run → Run Module, or enter python3 lantern-routes.py in the folder where you saved it.

Type 1 or 2 and press Enter for each decision. Open the file in a text editor to change the ROUTES entries. It runs offline using Python’s standard features.

Your first remix

  1. Predict. You start with three light. The cave costs two. The bridge costs one. The beacon needs two. Which route can light it?
  2. Play twice. Pick the beacon both times. Tell a partner what changes when you take the other route.
  3. Make one change. Give the cave a different cost or write a new ending. In Scratch, click the lantern and look for its orange change light by blocks. In Python, edit a route’s cost or the final print lines.
  4. Make it yours. Rename the two places after something in your own world. What does the train carry? Let a partner play and explain one choice you kept after watching.

When you share a remix, credit “Lantern Routes starter by APERTURE” and add a sentence about what you changed.
