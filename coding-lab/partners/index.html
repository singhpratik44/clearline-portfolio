Host a Creator Series workshop

Give a first-time coder and an experienced builder the same problem with two ways in. Each pair makes something another person can try. Families get a concrete example of the learning, and your staff gets a plan they can run again.

A 30-minute session

Choose a theme that already matters to your group. This example uses Court to Code. For a story club, try Playable Postcards. For a science group, try Rooftop Rain Lab.

  1. 0–5 min · Invent the moves. Partners pick two moves worth one and two points. Set the winning score to five.
  2. 5–15 min · Build a scorekeeper. First-timers act out both moves with counters and record the score. Builders ready for a stretch program the A and B buttons in Backyard Scoreboard.
  3. 15–24 min · Swap and test. A new player tries three two-point moves. The maker watches what happens at six points and revises the win rule.
  4. 24–30 min · Show the change. Each maker demonstrates a test and chooses one observation to record or print for family.

Illustrative report entry

The score skipped five

Skill
Test and debug · Build independently

Peer observation
“I pressed B three times. The score reached six and the round kept going. The maker changed ‘score equals 5’ to ‘score is at least 5.’ We restarted for each test. A, B, B won at five. B, B, B won at six.”

Next experiment
Set the target to seven. Predict which sequence reaches it exactly and which goes past it.

What makes APERTURE different

1. Build → Test → Explain → Improve

Every project ends with a working artifact, test evidence, a student explanation and a revision—not just completed worksheets.

2. Student choice, real constraints

Students choose games, robotics, sports or community challenges, then work within clear time, logic and accessibility constraints.

3. Debugging is the curriculum

Students predict outcomes, run experiments, diagnose failures and compare what changed. Mistakes become evidence.

4. A visible mastery trail

Keep a project example and an observation with each skill. Open a skills mastery report to review what the learner demonstrated.

5. Human-first AI literacy

Students distinguish simulations from AI, verify outputs, protect private data and retain ownership of their thinking.

6. Partner-ready instruction

Each pilot is designed around an instructor guide, demonstration, formative checks, accessibility adaptations and a showcase rubric.
