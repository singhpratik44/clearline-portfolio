Five non-negotiable learning artifacts

1 · Working creation

A playable game, simulation or robotics algorithm with a clear user goal.

2 · Prediction

A student explains what their code should do before running it.

3 · Test evidence

At least three cases, including an edge case, with expected and observed results.

4 · Debugging record

A failure, a hypothesis, a change and a retest.

5 · Showcase

A two-minute demonstration and next-iteration plan.

Four-week signature sequence

WEEK 1 · INVENT

Playable mechanics

Inputs, outputs, events, sequences. Build a movement or scoring loop.

Checkpoint: Demo works; learner can describe each input.

Stretch: Introduce two distinct player choices.

WEEK 2 · PROGRAM

Rules and state

Variables, comparisons, conditions and counters. Add a win/loss rule.

Checkpoint: Three tests with predicted results.

Stretch: Add reusable functions.

WEEK 3 · INVESTIGATE

Algorithms and debugging

Loops, edge cases, structured experiments and simple algorithm comparisons.

Checkpoint: One documented bug fixed and retested.

Stretch: Compare two strategies using evidence.

WEEK 4 · SHIP

Showcase and reflection

Accessibility check, usability feedback, improvement and presentation.

Checkpoint: Working demo, test log, explanation and next milestone.

Stretch: Create a project guide for another student.
