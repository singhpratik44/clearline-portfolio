Four-week learning arc

  1. Invent: student creates an interactive game or robot program
  2. Program: change variables, scoring rules and conditions
  3. Investigate: compare predictions and observed test results
  4. Showcase: demonstrate a working project and explain improvements

Evidence: working artifact, prediction, at least three tests, debugging note and student explanation.

Commercial and safeguarding gates

  • Define lesson files, cohort size, instructor support, dates, payment and refund terms before any paid agreement.
  • Keep APERTURE's pre-existing code and curriculum ownership; negotiate new jointly developed work in writing.
  • Do not collect identifiable minor student information on public GitHub Pages.
  • Use fictional data until security, privacy, access control and guardian consent requirements are independently reviewed.
  • No co-branding, public endorsement, or student enrollment before written approval.
