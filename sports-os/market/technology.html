← APERTURE SPORTS MARKETPLACE

Live sport, without pretending to own the game.

APERTURE's current marketplace links directly to official scoreboards, connects original in-house gift products and uses existing Stripe Payment Links. It does not embed real-time scores, copy broadcast footage, claim team/league partnerships, or use unauthorized team logos.

Implemented architecture

  • Static GitHub Pages frontend with no sign-in, adaptive mobile cards and original fan moment generator.
  • Browser-local fan moments that can be printed or shared in a URL fragment, without backend capture or advertiser access.
  • Existing live Stripe-hosted links reused from the APERTURE gift catalog; no payment keys on the site.
  • Independent sports scoreboards linked out to the league's own live results. APERTURE does not scrape these pages.
  • Advertising inventory defined as visible APERTURE placements with a one-time, review-gated fulfillment process.

Real-time licensing gate — not completed

Before showing a score ticker, obtaining provider scores/highlights or using team media assets commercially: confirm provider account access, commercial publishing rights, league and athlete rights, rate limits, API-key handling, renewal terms, attribution, retention/caching policy and allowed content surfaces. Do not place private API credentials into GitHub Pages JavaScript. A production aggregator needs a secured, licensed server-side data adapter and contract-compliant cache.

Sources checked November 12, 2026

  • TheSportsDB Terms of Use — free tier is suitable for development; published app-store apps require paid subscription and artwork/trademark rights remain separate.
  • Sportradar widgets — commercial widgets and linked API access are account- and product-dependent.
  • Sportradar data API — commercial real-time vs standard update modes with trial and licensing process.
  • NBA official games, WNBA, NFL, MLB, NHL — direct-score links rather than republication.
